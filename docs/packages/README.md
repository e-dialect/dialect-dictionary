# 导入一个资料包

这里的 `legacy-tsv-v1` 是本项目明确支持的**自有适配 profile**，不是中国语言资源保护工程的统一官方整包标准。依据已核验的旧 quick-start 说明，兼容五列 TSV 和四位编号关联音频；旧项目没有完整 manifest 规范，也没有可用的接口导入器。本实现独立使用 Python 和 Django，不复制无 LICENSE 的旧 SQL 生成代码。

## 1. 把资料整理为一个目录或 ZIP

```text
my-package/
  metadata.json
  words.tsv
  audio/
    0001太阳.wav
    0002月亮.mp3
```

ZIP 内也直接放这三项，不能再套一层 `my-package/`。不解压到磁盘；读取有上限：5000个目录/文件条目、单文件32MiB、总计128MiB。禁止绝对路径、`..`、符号链接、特殊文件、加密 ZIP；超限、未知文件或 FLV 失败，不会伪装导入成功。WAV 支持非空单/双声道 PCM；MP3先做头部检查，不等同于完整解码/试听验收。FLV应由有权操作者另行转成可播放 WAV/MP3，当前命令不自动转码。

`words.tsv` 首行按下面五列，以真正 TAB 分隔。支持 UTF-8（可BOM）和有BOM的UTF-16LE/BE，LF/CRLF。每条数据必须五列；不支持单元格内换行。词表编号为1–4位十进制数字（例如`1`或`0001`），不是数据库主键；音频匹配时补足四位，原词表编号另保留，`1`与`0001`同时出现视为冲突；一条词必须且仅有一个关联音频，音频名前四位必须与编号相同，之后不能再接数字。缺失、多余或重复音频会显示具体行/文件错误。

```text
编号    普通话    方言    发音    注释
0001    太阳      自有词  tʰai    自有释义
```

上面空格仅用于说明列；实际文件请用TAB。发音列是IPA，原样存储，不猜测方言拼音；拼音字段留空。目录中的文字和录音都需要合法来源、许可与被录音者的适当同意；不要把真实资料提交进Git仓库。

`metadata.json` 示例：

```json
{
  "profile": "legacy-tsv-v1",
  "package_id": "my-source-v1",
  "source": "实际资料来源、整理者及版本说明",
  "license": "实际许可或授权范围说明，不要猜测",
  "dialect": {
    "county": "实际县区或明确的适配值",
    "town": "实际乡镇或明确的适配值",
    "mapping_note": "说明来源方言如何对应当前词典地区字段"
  },
  "publication": {
    "authorized": false,
    "statement": "未获对外公开许可，先私有导入"
  }
}
```

`source`、`license`、地区和映射说明都不能为空。`package_id`使用1–120位ASCII字母/数字/点/下划线/连字符。后端保存完整元数据、包内容SHA256、导入用户名、时间、原编号和数据库映射，支持追溯。元数据声明不是软件替你取得许可；不能因为成功校验就认为资料已获公开授权。

## 2. 先预览，再导入

按根 README 初始化站点。纯校验不写数据库、媒体或暂存文件，报告编码、行号、词条/音频关联和错误：

```sh
./dictionary preview packages/examples/synthetic-legacy-v1
```

应用导入需要已经初始化的后端，以及一个实际存在的导入用户名，不填数据库ID、不默认user1、不创建登录账号：

```sh
./dictionary import /absolute/path/to/my-package --importer existing_username
```

默认词条和语音未公开，媒体只存 `/data/private-imports/`，**不会**放入公开的 `MEDIA_ROOT`。私有媒体没有可供匿名读取的URL；仅隐藏按钮或设 `visibility=false` 不能保护公开路径中的文件，因此这里根本不发布这些文件。

只有确认该包文字和录音均有对外公开授权，才在 metadata 中填写 `publication.authorized=true` 和真实的包级公开授权说明，再显式执行：

```sh
./dictionary import /absolute/path/to/authorized-package --importer existing_username --publish
```

`--publish`还须配合实际应用导入；单独预览不会发布。公开后媒体进入包隔离目录，词条/语音才设为公开，URL使用当前站点API端点。不可使用不属于自己的真实资料来验证此步骤；仓库的 `packages/examples/synthetic-legacy-v1` 只有原创合成文字和程序生成的数字静音，明确CC0，不代表真实语保资料或方言。

## 3. 重复与失败处理

同一包ID、相同完整内容SHA256、相同公开状态重导会跳过，不重复创建。相同ID内容改变或公开状态改变会拒绝；请核验来源后为新资料版本使用新ID。两个不同包都含 `0001` 可以共存，数据库词条ID独立生成。当前不做无声覆盖、跨包去重、自动合并或私有包升级公开。

先在私有目录暂存全部已校验音频，然后独占创建该包存储目录；数据库记录处于一个事务，运行期间失败会回滚数据库并清除本次创建的公开/私有文件，不覆盖或清理既有包。文件系统与数据库不是跨资源分布式事务：**进程被强杀或主机掉电**可能遗留独占目录。此时重试拒绝覆盖该目录；先停写、备份并由操作者核对导入回执和目录，不要直接删除有价值资料。当前没有承诺崩溃下完全自动恢复。若公开导入发生崩溃，已确认可公开的媒体可能先于数据库提交可达；未获公开授权的媒体仍只在私有目录。

启用可选语义索引的部署应按其原工具重建索引；轻量部署使用既有关键词检索。导入采用已验证字段的ORM批量写入，保真IPA，不伪造拼音，也不声称执行了旧Web审核流程。

## 尚未支持的真实包形态

当前未取得可公开测试的真实语保整包样本。其他Excel列名、说话人多录音层级、视频/FLV、跨行注释、超过四位或非数字编号、另一份官方目录标准都不能宣称已适配；先保留原包，只将**已授权**的目录结构/表头/媒体命名约定作为下一profile的依据。不要为绕过校验改写资料来源或许可。真实数据与个人信息不入仓。
