# 用网页选择 ZIP 并只读预览

**本地候选功能：已实现代码及静态检查，尚未运行自动测试或浏览器验收，未推送或部署。** 原有命令行预览和导入仍见[资料包指南](README.md)。本页不是线上已更新的承诺。

## 你会看到什么

1. 先按[安装指南](../install.md)启动自己的站点，用已有运营账号登录 `/api/admin/`，打开“网页内容”。在首页配置上方点击“选择 ZIP 资料包 → 只读预览（不导入）”。首页配置尚未创建时也有这个入口，无需为了预览先创建配置。
2. 点击“选择文件”，选一个 `.zip`，再点击“只读检查并预览”。ZIP内根目录应直接包含 `metadata.json`、`words.tsv` 和 `audio/`，不要再套一层资料夹；支持格式和示例见[资料包指南](README.md#1-把资料整理为一个目录或-zip)。
3. 检查结果显示包标识、来源、许可声明、方言对应、词表编码、内容摘要、词条行号和录音关联。IPA按原文字显示，不推测拼音。缺失/多余录音、FLV、编码和来源问题会提示文件名或行号；详细校验错误目前可能含英文。
4. 有问题时保留原件，只修改副本，再次选择文件重新检查。通过格式校验仍须自己核对内容、录音质量和授权，不能证明资料已获公开许可。页面不播放录音、不提供媒体下载地址。
5. 点击“取消/返回后台首页”即可退出。这个入口没有“导入”或“公开”按钮，重复预览也不会创建词条、录音、导入回执或导出文件。要实际导入，当前仍需按资料包指南执行命令并指定已有导入者；网页确认导入尚未实现。

看不到入口时，当前账号可能没有已有的“资料包 / 可查看”权限。具备该权限的后台账号可直接进入 `/api/admin/website/website/package-preview/`。请联系站点管理员核对账号，不要改安全设置；本功能不自动授予权限，也不新建账号。

## 大小限制与私有临时文件

- 网页ZIP文件最多19 MiB；整个HTTP请求最多20 MiB，包含表单开销。既有Nginx也限制请求20 MiB，若代理先拦截可能只显示413页面，此时请使用本地预览命令，不要反复上传。
- 这不是解压大小限制。共用校验器另限制最多5000项、单文件32 MiB、展开内容合计128 MiB；直接读取ZIP成员，不解压到公开目录。拒绝路径穿越、绝对路径、符号链接、特殊文件、加密ZIP和不支持的格式。
- 网页请求先由Django正常处理上传，再将受限副本写到系统私有临时目录，完成或出现普通异常时清理。不会写入 `MEDIA_ROOT`、私有导入目录或导出目录，不发送给第三方服务。进程强杀/掉电可能留下私有系统临时文件，需按服务器日常临时文件管理处理，不能声称崩溃时即时清除。未改变系统目录权限或全局上传处理器。
- 结果不进入共享HTTP缓存。页面最多显示前50行及前100条错误；较长文字会明确标注截短，完整校验覆盖整个包，原文件不变。要保留完整错误请使用本地命令预览；不要把含私有资料的结果或截图公开分享。
