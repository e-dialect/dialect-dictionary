1. 从后台“网页内容”进入当前生效首页；按标题搜索返回公开状态、日期和预览入口。
2. 含HTML/脚本形状的标题按文本显示；文字预览去除标签。私有草稿有明确“不会在网站显示”标识。

4. 移除后“恢复打开时的选择”恢复当前页初始列表；移除后取消返回再打开，原保存列表未改变。
5. ZIP只读预览入口可打开，页面说明不导入、不公开及文件大小限制。
