# 包级导入与部署入口重构验证

本轮从公开 main `e368738089dc4f0b9a62345b79a48f004ad825d5` 的干净状态开始，在 `feat/package-onboarding` 隔离分支实施，不直接修改 main。面向用户的入口是根 `dictionary` 命令、README、资料包和部署指南；应用归入 apps，运维配置归入 ops，工具归入 tools，来源和历史验收归入 docs。

## 真实完成的实现

- 不再以 integrations 文档壳代替导入。独立编写 legacy-tsv-v1 目录/ZIP校验与导入，不复制无LICENSE SQL生成器。该profile是本项目适配格式，不是官方整包标准；目前只核验了已知五列TSV格式，没有真实授权资料包用于通用适配。
- 无写入预览含编码、行号、来源、原编号/媒体关联及错误。导入使用已有用户名，ORM生成全局记录ID，回执保留包ID/digest/来源许可和原编号；相同包/状态幂等，同ID变更或公开状态切换拒绝，不无声覆盖。当前不提供就地公开/撤回。
- 默认私有数据和媒体。只有显式publish加包级授权声明才公开；未授权、非法包与受控失败不能留下公开媒体。文件和DB不是跨资源原子事务，掉电/强杀的独占残目录边界在资料指南明确说明。
- 修复新私有导入触及的旧读取边界：匿名批量查词不再返回私有词条，私有语音详情受owner/admin保护，404不再被旧中间件改为500。详情浏览只更新计数，不再调用clean改写IPA与破坏录音匹配。
- 已有Traefik方案移除网站host端口，后端仅内部；Nginx固定覆写https，Django仅代理模式信任该头。管理反向URL/static保留/api前缀。独立新服务器Traefik为显式第三overlay，使用自己的网络/ACME卷，不接管已有网络。
