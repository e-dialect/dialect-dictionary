# 中文使用指南

这套服务把自己的方言词条与录音整理成电脑网页、手机网页。先在本机试用，再考虑有域名的服务器。微信小程序要另外完成 AppID、服务器域名和平台审核，Compose 不会直接发布小程序。

## 目前验证到哪里

已经在同一台机器的隔离目录/数据卷中，从源码重新构建后端、Web 和 H5，验证资料包导入、录音字节与解码、公开/私有权限和 Nginx 代理链。使用的都是原创合成词条与数字静音，不是真实方言资料。

已有 Traefik 方案验证了配置合并和内部 HTTP 代理行为；独立 Traefik 只做配置校验。尚未验证另一台机器、真实公网 TLS/证书续期、真实语保整包、微信真机或平台审核。详细版本、测试方法与边界见[验收记录](development/onboarding-validation.md)。健康检查通过不等于所有业务或授权正确。

## 命令的阅读方式

本文档的命令在包含 `dictionary`、`compose.yaml` 的根目录执行，使用 Bash 或 Zsh。Windows 用户请在已配置 Docker 的 WSL 环境运行；本轮没有做 Windows/WSL 实机验收。`/你的路径/资料包.zip`、`你的用户名`等是需要替换的示例，含空格的路径须放在双引号内。文件名、配置键和命令参数保持英文原样，不要翻译。

真实资料、录音、账号和备份的授权由使用者确认。软件许可不替代数据许可；源码署名、许可证和来源说明必须保留。
