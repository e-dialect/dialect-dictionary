# 在网页后台管理公告

这是当前隔离分支的候选功能，尚未完成浏览器验收；不要把本文当作线上已经更新的说明。

1. 使用自己已有的运营账号进入网站的 `/api/admin/`，打开“网页内容”，选择编号为1的首页配置。若没有访问权限，请联系站点管理员；不要修改安全设置来进入。
2. 在“公告管理”输入标题关键词，点击“搜索文章”。每张结果卡显示标题、是否公开和发布日期；“文字预览”只显示文字，不执行文章中的HTML或脚本。
3. 点击“加入公告”，在“已选公告”用“上移”“下移”调整顺序，或“移除”。这里的顺序就是网站的新请求读取顺序；重复加入不会多出一条。
4. 加入“未公开”的文章不会让它通过审核，也不会在网站公开显示。只有本来具备文章查看权限的人才可搜索或预览未公开内容；已有选择中的无权查看项只显示编号占位，不泄露标题或正文。
5. 点击Django页面底部的“保存”。重新打开配置核对顺序，再打开网站确认效果；设计上保存后新请求直接读数据库，无需重启服务。当前浏览器完整操作仍待验收。

不想保存时点击“取消并返回（不保存）”；“恢复打开时的选择”只恢复当前页面最初打开的列表，之后仍需自己选择是否保存。搜索、预览、加入和上下移动本身都不保存。

原来的合法文章编号列表仍兼容，不需要迁移数据库。旧配置若格式不正确，会提示错误并保留原值，不会自动清空；请先备份，再由管理员核对，不要反复保存来掩盖问题。

本轮只改善公告。站名、方言和端点目前仍按[安装指南](install.md)配置；密钥、数据库连接、网络和安全设置保持独立，不加入普通运营后台。热门文章、每日一词和轮播仍保留旧格式，不能据此声称所有运营配置已经网页化。
