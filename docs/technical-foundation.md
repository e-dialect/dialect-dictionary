# 技术二：共性数字服务底座的可核验证据

这一候选支撑“同一套词典服务，以配置形成不同地方的独立数字服务”，范围是可部署词典能力复用，不扩展为多租户平台、插件市场或共享数据库，也不要求两仓实时同步。

| 共性能力 | 本轮落地 | 验证位置 |
| --- | --- | --- |
| 地方品牌与内容源配置 | 站名、标识、方言、端点、来源提示、基本功能开关 | `config/examples/`、两端 `src/config/` |
| 多端服务复用 | Django API + Web + Uni-App H5/小程序源码同仓；补齐移动端词条申请 | `backend/`、`web/`、`uni-app/` |
| 独立实例部署 | Compose、独立 SQLite/媒体卷、健康检查、配置挂载 | `compose.yaml`、`deploy/` |
| 内容与权属边界 | 自编技术演示条目，保留数据来源/资产授权文件，默认隐藏原方言专属工具 | 各组件许可证与资产说明 |

演示可比较海岚/nan与山城/hak两份配置，但不声称已经拥有对应语言的真实词典或音频。Web/H5启动、静态构建与小程序真机/发布必须分别说明。

本轮由已授权的 GPT 本地实现推进，不给两个学生组新增春节前任务，不改其主线，也不触碰乡声集盒在途 PR。后续若纳入展示，应使用验证记录中的实际结果，不把尚未完成的真机、内容授权或生产部署写成已完成。
